# scripts

One line per folder. Each script's header comment says how to run it.

| Folder         | What it does                                                                                                                                                                                                                                                                                                       | Run through                                     |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| `fullstack/`   | Starts and stops the local stack (mongod, redis, api, worker, bridge, a fake judge, the SPA preview)                                                                                                                                                                                                               | `npm run stack:up`, `npm run stack:down`        |
| `judge/`       | `judge-v2-up.sh` runs the real judge-v2 against that stack; `check-deploy-copies.sh` checks `deploy/judge/*` against judge-v2 `packaging/`; `emit-init-fixtures.ts` writes every `init.yml` shape into judge-v2's fixture directory; `parity/` is the rejudge-and-compare gate for a problem flip (its own README) | `npm run judge:v2:up`; the other two by hand    |
| `judge-proto/` | Syncs the vendored `qhhoj.judge.v1` contract from a judge-v2 tag and checks it against `proto.lock.json`                                                                                                                                                                                                           | `npm run judge-proto:sync`, `judge-proto:check` |
| `lint/`        | `check-plan-ids.sh` fails CI when a source comment names a plan, task or preflight id                                                                                                                                                                                                                              | CI job `checks`                                 |
| `release/`     | `tag-release.mjs` tags `v<version>` after the Version PR merges (idempotent)                                                                                                                                                                                                                                       | `npm run release:tag`                           |
